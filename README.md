# zapret-blobs
Сборная солянка всяких бинарников с разными пейлодами. 

Форматы названий файлов:
1) Протокол_Домен2_Домен1.bin (где 2 и 1 - уровни домена)
2) Протокол_Флаги.bin
3) Протокол.bin (или ПротоколN.bin, где N - номер файла)

**Зачем это нужно?**

Всё очень просто, некоторые блокировки могут пробиваться нестандартными блобами. 

Приведу пример из личного опыта: мой провайдер блокирует QUIC на UDP 443 к discord.com, отправка фейков с блобом QUIC Initial google.com у меня не пробивает блокировку. Конечно, можно было обойтись сменой блоба на другой QUIC Initial, но мне было лень искать другой бинарник QUIC, поэтому я решил взять и выгрузить пейлод DNS запроса к yandex.com и выставить его в качестве блоба для фейков. И это помогло пробить блокировку discord по QUIC.
